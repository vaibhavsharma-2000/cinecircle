# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Next.js 15 (React 19, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion), Supabase (PostgreSQL, Auth, RLS), TMDB API v3.

## Users
Small friend circles (10–20 friends) who want to share movie & TV show recommendations, track personal watchlists, rate titles on a 5-star scale, and effortlessly decide what to watch on movie nights.

## Product Purpose
CineCircle is a private, high-trust, UX-first movie & TV show recommendation platform. It replaces cluttered public algorithms with personal friend reviews, custom mood discovery, and shared decision tools.

## Positioning
Private friend circle network + 5-Star high-trust reviews + "What Should We Watch Tonight?" group watchlist matcher + TMDB API discovery engine.

## Operating Context
Web application used on desktop and mobile browsers by friends for post-movie rating, daily film tracking, and group movie night decision-making.

## Capabilities and Constraints
- 100% Free technical stack (Next.js 15, Supabase Free Tier, TMDB API v3, Vercel hosting).
- 5-Star rating system (1.0 to 5.0 with half-stars).
- Pop-culture character avatars (Tony Stark, Wednesday Addams, Luke Skywalker, Michael Scott, Barbie, Batman, Hermione Granger, Miles Morales).
- 1-Click frictionless user flows (Search-to-Recommend, Instant Watchlist save, Embedded YouTube trailer streaming).
- Warm Cinema & Golden Amber Design System (Pitch-black canvas `#08080A`, dark charcoal surfaces `#121216`, golden amber accents `#F59E0B`, zero purple tint).

## Brand Commitments
- Name: CineCircle
- Voice: Minimalist, cinematic, high-editorial, friend-focused.

## Evidence on Hand
- Live TMDB API key & Supabase project configured in `.env.local`.
- Production build passing with 0 errors (`npm run build`).

## Product Principles
1. High-trust friend recommendations over public crowd noise.
2. 1-Click frictionless interactions (minimal user steps).
3. Minimalist cinematic editorial design with warm amber accents.
